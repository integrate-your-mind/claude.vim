INTRODUCTION                                      *claude-vim-introduction*

claude.vim is a Neovim plugin that integrates Claude Code directly into your
editor, providing seamless AI assistance without leaving your development
environment.

Features:
- Direct Claude Code CLI integration
- Terminal mode for interactive sessions
- Floating window mode for quick responses
- Smart window management with singleton behavior
- Code explanation and file review capabilities
- Highly configurable terminal and floating window behavior

Requirements:
- Neovim 0.8+
- Claude Code CLI installed and configured

==============================================================================
INSTALLATION                                      *claude-vim-installation*

Using lazy.nvim: >
    {
      "integrate-your-mind/claude.vim",
      config = function()
        require("claude-code").setup()
      end,
    }
<

Using packer.nvim: >
    use {
      "integrate-your-mind/claude.vim",
      config = function()
        require("claude-code").setup()
      end
    }
<

Using vim-plug: >
    Plug 'integrate-your-mind/claude.vim'
<

Then in your init.lua: >
    require("claude-code").setup()
<

CONFIGURATION                                    *claude-vim-configuration*

The plugin can be configured using the setup function: >

    require("claude-code").setup({
      claude_executable = "claude",
      default_mode = "terminal",
      terminal = {
        position = "right",
        size = 80,
        close_on_exit = false,
      },
      floating = {
        width = 0.8,
        height = 0.8,
        border = "rounded",
        animation = {
          enabled = true,
          duration = 200,
        },
      },
    })
<

Configuration options:

*claude_executable*      (string, default: "claude")
    Path or command name for the Claude CLI executable.

*default_mode*           (string, default: "terminal")
    Default interaction mode: "terminal" or "floating"

*terminal.position*      (string, default: "right")
    Terminal position: "right", "left", "bottom", "top"

*terminal.size*          (number, default: 80)
    Terminal size (width for vertical, height for horizontal splits)

*floating.width*         (number, default: 0.8)
    Floating window width as percentage of screen width

*floating.height*        (number, default: 0.8)
    Floating window height as percentage of screen height

*floating.border*        (string, default: "rounded")
    Border style: "single", "double", "rounded", "solid", "shadow"

COMMANDS                                            *claude-vim-commands*

*:ClaudeChat* [prompt]                              *:ClaudeChat*
    Open Claude terminal or send prompt to existing terminal.
    If [prompt] is provided, it will be sent to Claude.

*:ClaudeFloating* [prompt]                          *:ClaudeFloating*
    Open floating window with Claude response.
    If [prompt] is provided, it will be sent to Claude.

*:ClaudeToggle*                                     *:ClaudeToggle*
    Toggle Claude terminal visibility.

*:ClaudeStatus*                                     *:ClaudeStatus*
    Show Claude connection status in floating window.

*:ClaudeExplain*                                    *:ClaudeExplain*
    Explain selected code (use in visual mode).

*:ClaudeReview*                                     *:ClaudeReview*
    Review current file for potential improvements.

*:ClaudeMode* {mode}                                *:ClaudeMode*
    Switch between "terminal" and "floating" modes.

FUNCTIONS                                          *claude-vim-functions*

*claude-code.setup*({config})                      *claude-code.setup()*
    Setup the plugin with optional configuration.

*claude-code.chat*({prompt}, {mode})               *claude-code.chat()*
    Start Claude chat with optional prompt and mode.

*claude-code.chat_terminal*({prompt})              *claude-code.chat_terminal()*
    Open Claude in terminal mode with optional prompt.

*claude-code.chat_floating*({prompt})              *claude-code.chat_floating()*
    Open Claude in floating window with prompt.

*claude-code.toggle_terminal*()                    *claude-code.toggle_terminal()*
    Toggle Claude terminal visibility.

*claude-code.status*()                             *claude-code.status()*
    Show Claude status in floating window.

*claude-code.explain_selection*()                  *claude-code.explain_selection()*
    Explain currently selected code.

*claude-code.review_file*()                        *claude-code.review_file()*
    Review current file with Claude.

*claude-code.get_status_line*()                    *claude-code.get_status_line()*
    Get Claude status for status line integration.

KEYBINDINGS                                        *claude-vim-keybindings*

Default keybindings (can be customized):

*<leader>cc*    (Normal)    Open Claude chat
*<leader>ct*    (Normal)    Toggle Claude terminal
*<leader>cf*    (Normal)    Open Claude floating window
*<leader>cs*    (Normal)    Show Claude status
*<leader>ce*    (Visual)    Explain selected code
*<leader>cr*    (Normal)    Review current file

Terminal mode keybindings:
*<C-q>*         (Terminal)  Exit terminal mode
*q*             (Normal)    Close terminal (when in terminal buffer)

Floating window keybindings:
*q*             (Normal)    Close floating window
*<Esc>*         (Normal)    Close floating window
*<C-t>*         (Normal)    Switch to terminal mode

EXAMPLES                                            *claude-vim-examples*

Basic usage: >
    " Open Claude terminal
    :ClaudeChat

    " Ask a specific question
    :ClaudeChat "Explain this function"

    " Get Claude status
    :ClaudeStatus
<

Lua usage: >
    -- Open Claude terminal
    require("claude-code").chat_terminal()

    -- Send prompt to floating window
    require("claude-code").chat_floating("Explain async/await")

    -- Explain selected code
    require("claude-code").explain_selection()
<

Custom keybindings: >
    vim.keymap.set("n", "<leader>ai", function()
      require("claude-code").chat_terminal()
    end, { desc = "Open Claude AI" })
<

TROUBLESHOOTING                                *claude-vim-troubleshooting*

Common issues and solutions:

*Claude CLI not found*
Ensure Claude Code CLI is installed and in your PATH, or specify the full
path in configuration: >
    require("claude-code").setup({
      claude_executable = "/path/to/claude",
    })
<

*Terminal not opening*
1. Check that your terminal supports Neovim's terminal features
2. Verify Claude CLI is working: `claude --help`
3. Check debug logs in `claude_debug.log`

*Multiple Claude instances*
The plugin uses singleton behavior to prevent duplicates. If you see multiple
instances, check the debug logs for issues.

*LazyVim import order warnings*
Add to your lazy.lua config: >
    vim.g.lazyvim_check_order = false
<

For more help, see: https://github.com/integrate-your-mind/claude.vim
